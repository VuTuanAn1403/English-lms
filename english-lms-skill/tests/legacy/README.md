# THƯ MỤC KIỂM THỬ LỊCH SỬ (LEGACY TESTS ARCHIVE)

> ⚠️ **CẢNH BÁO: TÀI LIỆU VÀ SCRIPT KIỂM THỬ LỊCH SỬ - KHÔNG CÒN LÀ NGUỒN SỰ THẬT.**
> Các file script trong thư mục này thuộc về các bước kiểm thử cũ (vutuanan seed, step-by-step verification cũ).
> Đã được thay thế bởi bộ kiểm thử tự động chuẩn hóa tại:
> - Backend Unit & Security Tests: `<module>/src/test/java` (JUnit 5)
> - Centralized Integration & Smoke Tests: `tests/smoke/smoke-test.py`
> - Centralized API Tests: `tests/api/api-test-suite.py`
> - Full Test Runner: `tests/scripts/run-all.ps1` & `tests/scripts/run-all.sh`
