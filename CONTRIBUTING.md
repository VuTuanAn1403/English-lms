# Contributing to English LMS

Thank you for considering contributing to **English LMS**!

## How to Contribute

1. **Fork & Clone**: Clone the repository locally.
2. **Branching**: Create a feature or fix branch (`git checkout -b feature/amazing-feature`).
3. **Environment**: Copy `.env.example` to `.env` and set local variables.
4. **Code Guidelines**:
   - Ensure Java 17 and Spring Boot microservice standard coding practices.
   - Maintain unit test coverage for new endpoints and business logic.
   - Keep frontend React components modular and typed/documented.
5. **Testing**: Run `mvn clean test` and `npm run build` prior to committing.
6. **Pull Request**: Open a PR with clear description of changes.
